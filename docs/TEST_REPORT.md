## 本轮布局变更

舞台轨道等比放大25%，原有顶部展示板与底部提示的占位取消；HUD移至紧凑顶部区域。背景cover、轨道fit两套独立等比变换，并使用相同变换逆矩阵做触控/鼠标命中。像素版外框顶边额外下移16设计像素，音符入场位置避让顶栏；下方判定位置保持不变。五种窗口尺寸均验证顶栏文字与轨道外框安全间距。核心判定、谱面、计分逻辑无改动。最终自动导入和headless主场景启动均无脚本/资源错误。

## 范围说明

自动化测试的 headless 画布检查不等于 GPU 截图验证；图形界面检查另行进行。未声称测试音频同步、浏览器导出、第三方触控设备、真实音乐延迟或联网，因为这些功能不在当前实现范围。
