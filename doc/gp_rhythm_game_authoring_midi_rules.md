# Bad Apple MIDI 规则试验

工程：`baddapple_MIDI规则试验`。编辑器谱面库刷新后打开，也可在游戏选曲中选择。
输入是用户提供的 `BadApple_feat_nomico_Godot_MIDI_events.json`，标注来源为
`【MSGS】Bad Apple!! feat. nomico.mid`。没有下载第三方制谱程序或复制其代码。
现有音源来源和使用范围见 `../charts/bad_apple/SOURCE.md`。

## 参考与本项目取舍

- [osu!mania mapping guide](https://osu.ppy.sh/wiki/en/Guides/osu%21mania_mapping_guide)：先检查 BPM 与 offset；长按表达持续声，双押强调重音，密集同键连击需要节制。
- [Automap-chan 作者教程及示例](https://osu.ppy.sh/community/forums/topics/382896)：将 MIDI 中选定的声部分配为可演奏音符，按难度减少事件并限制和弦规模。这里采用选声部与限制同时按键的思路，编排规则自行实现。
- [osu! hitsound 说明](https://github.com/ppy/osu-wiki/blob/master/wiki/Beatmapping/Hitsound/en.md)：持续交互中的被动音效可以落在明确节奏点。本项目将连续闭镲织体处理为保持动作，内部 Sub 保留逐次反馈。

“三连闭镲变长按”是用户示例启发的游戏规则，并非教程要求，也不表示鼓声本身持续发音。三连指每拍 0、0.25、0.5 的三个十六分位置，不是三连音。

## 第 0 拍校准

- MIDI 分辨率 480 tick / 四分音符，采用已知 BPM 138。
- 对实际 `bad_apple.ogg` 与 MIDI 音高变化做全曲匹配，最佳移位约 -1.6602 秒，且无需移调；避免只根据重复鼓点产生整拍歧义。
- 0–30、30–75、75–125、125–175、175–217 秒窗口的匹配位移分别为 -1.6602、-1.6718、-1.6602、-1.6486、-1.6486 秒。分析步长约 11.61 ms；这是粗时间对齐证据，不表示毫秒级人工听感已验收。
- MIDI 开头有 4 拍准备区。新工程以 MIDI 第 4 拍作为编辑器第 0 拍。选定网格起点 **79.13 ms**，即 `4 × 60000 / 138 − 1660`。这一整体位置也与现有源 SM 的 OFFSET=1.660 相符，但生成器不读取原游戏谱面音符。
- 开头和前半段的高频起音检查约落在 76–85 ms；末段鼓点提取受配器影响，不能用单个频段峰值强行改变整首 BPM。全曲音高匹配未出现持续累积漂移。
- 换算：`编辑器拍数 = tick / 480 − 4`，`音频毫秒 = 79.13 + 编辑器拍数 × 60000 / 138`。
- JSON 自带的 t 包含 MIDI 初始速度段，不用于直接计算游戏位置。游戏的五秒准备和玩家音画/输入校准不计入谱面时间。
- 用户原示例的 36–42.5 拍模式，在校准后的工程中位于 **32–38.5 拍**。不修改原示例。

## 确定性编排规则

1. 以十六分音符网格读取 MIDI，偏离最近格超过 0.08 拍的事件跳过。丢弃力度小于 10 和音源范围外的事件。同声部同拍折叠。
2. 底鼓映射到一侧。另一侧负责闭合踩镲和开放踩镲；每 8 小节交换角色，长按不跨越换手边界。
3. 闭镲力度至少 40，且存在 `b、b+.25、b+.5`、不存在 `b+.75` 时识别三连模式。逐拍重复时合并，最多包含 8 组。首尾为长按端点，其余事件为 Sub。
4. 未参与长按的闭镲只保留八分位置、力度至少 60 的事件。开放踩镲/脚镲保留八分位置、力度至少 50 的事件；同拍已有闭镲则不重复添加。
5. 边击/拍手与底鼓归于同侧；强镲（力度至少 85）在另一侧强调重音，与已有点重合时合并。嗵鼓（力度至少 65）允许十六分过门。
6. 长按期间同轨不新增独立单击：重要底鼓、边击、强镲、嗵鼓尝试移到空闲手；仍不可用则省略。闭镲 Sub 只来自原闭镲事件，不随意填充。
7. 没有明显鼓点的小节允许加入力度至少 110、位于八分位置的人声起音，合并叠音，不从该人声轨推断长按长度。
8. 最后一个鼓点之后，轨道 3/4/9 中力度至少 70、至少持续 1 拍的伴奏音可生成长按。同起点和弦折叠；最多 8 拍，在下一起音之前收尾。不将其标作真实人声长音。
9. 每轨每拍只有一个点，长按头尾不重复计为 Sub，所有端点配对，生成后通过现有库编译和范围/重叠检查。

## 本次生成结果

894 个单击、10 条长按（8 条闭镲纹理、2 条尾段伴奏）、146 个 Sub，共 1060 个判定单位。
左右头部数量 462 / 442；最高每秒 9 个头部，同轨头部最短间隔约 217.4 ms。
首音 79.13 ms，末判定约 216.275 秒。难度暂标 `Normal / 规则试验`，由人工试奏评定。
示例段右轨 32–38.5 拍有 19 个 Sub，左轨 32–39 拍各一个底鼓单击。

## 重新生成

以下是离线素材生成命令，不用于启动编辑器或游戏。在本目录执行，标准库即可生成；使用新工程名防止覆盖人工修改：

```powershell
python -B generate_midi_rules.py --source "C:/Users/81010/Desktop/BadApple_feat_nomico_Godot_MIDI_events.json" --name "baddapple_MIDI规则试验_第二版" --bpm 138 --midi-origin-beat 4 --offset-ms 79.13
```

源 JSON 保留在用户提供位置，脚本不复制或改写它。`--name`、`--bpm`、`--midi-origin-beat`、`--offset-ms` 可显式指定；已有同名工程会拒绝覆盖。
生成器只新增谱面数据，不修改同步、判定、音效设置或编辑器播放机制。
