# DUET / 双生节拍

独立 Godot 4.7.2 项目。双键、双轨下落式玩法，包含三个可完整游玩的原创视觉篇章。不是三个配色皮肤：透视舞台、像素夜站、雕塑光影分别使用独立场景与绘制实现。

## 运行

用 **Godot 4.7.2** 导入 `project.godot`，运行主场景 `ui/main.tscn`。不依赖插件、网络服务或商业素材。支持桌面键盘、鼠标判定区域及双指触屏。

- 左轨：D / F / ←；右轨：K / J / →
- 两条轨道同时出现音符时，同时按左右键
- 触屏：点击屏幕下方左右区域；鼠标可点击底部左右判定区域
- ESC：暂停 / 继续；失去窗口焦点自动暂停
- 继续演奏前有两秒缓冲倒计时
- 菜单的「动态效果」按钮可切换舒缓模式，静止环境运动并关闭击打扩散粒子，保留必要音符下落和按键反馈
- 标准流程：选择世界 → 选择难度 → 进入舞台 → 暂停或完成 → 成绩 → 重试或返回

三个世界都包含 48 秒完整谱面与结算；漫步与跃动具有不同密度。每局有起始倒计时，判定光线在画面下部。音符颜色及形状共同区分轨道，非仅靠颜色。

## 三个视觉篇章

1. **霓虹回响 / LUMINOUS**：青粉双轨、透视悬浮跑道、分段舞台天幕、LED 塔、扬声器、观众剪影与光束。厚切斜角音符和碎光环击打，接近现场演出的视觉重心。
2. **午夜电台 / AFTER HOURS**：平行像素轨道、深夜站台、雨线、窗灯城市、短波收音机、戴围巾的旅人和小猫。琥珀与珊瑚矩形音符使用心电/磁带图案，暖色低照度叙事情境。
3. **浮光之间 / AETHER**：青绿与暖白光影、浮石与轨道雕塑、月牙、悬挂珠体、萤火粒子。珠光音符与椭圆涟漪判定，留白和缓慢环境运动强调呼吸感。

游玩画面采用全幅演出构图：放大后的双轨从顶栏下方延伸至底部判定区，仅保留曲名、分数、连击、判定、进度、剩余时间及暂停按钮。游玩、暂停和结算不显示品牌展示头栏、风格编号、装饰英文标记或操作提示。按键说明仅出现在选曲菜单。测试独立于正式主场景。

## 判定与计分

- PERFECT：时间误差不超过 70ms；GOOD：不超过 150ms；超过 150ms 未击中记 MISS
- 每个音符只能消费一次；按住、键盘自动重复、别名键同时按下不会重复计分
- 和弦独立判定两条轨道；误按空轨不获得分数
- 分数上限 1,000,000；PERFECT 权重 1，GOOD 权重 0.65；MISS 打断连击
- 准确率是已经判定音符的加权准确率；未判定不纳入分母
- 结算提供等级、总分、准确率、判定计数与最长连击
- 暂停冻结谱面时钟；重开重置所有计分、输入状态、粒子和计时；返回选曲取消旧局

## 当前边界

本次按需求优先完成视觉、UI 和双键可玩流程。**不包含音乐文件、声音播放或真实音频时钟同步**。谱面由本地帧推进的确定性时间模型驱动，不代表任何参考作品或歌曲的正式谱面。48 秒为本项目自有视觉节奏段长度。尚未实现长按、滑键、延迟校准、曲库导入、联网、成绩持久化和可直接部署的 Web 导出；源码可以在安装官方导出模板后继续扩展。不能把这些未实现能力当作现有功能。

## 场景与代码

- `ui/main.tscn`：可在编辑器直接修改的菜单、HUD、暂停、结算节点及布局
- `ui/main.gd`：场景切换、主题、双键/触屏输入、多输入源去重、暂停恢复与结果展示
- `core/rhythm_session.gd`：与 UI 解耦的谱面、计时、判定和计分模型
- `skins/neon.tscn` / `.gd`：原创矢量舞台及透视音符
- `skins/pixel.tscn` / `.gd`：原创像素场景及平行轨道
- `skins/aurora.tscn` / `.gd`：原创雕塑光影及珠光音符
- `tests/`：自动化模型和集成测试，仅由命令行运行

设计基准 1920×1080，以 Godot `canvas_items` + `expand` 适配窗口；默认1280×720，最小640×360。非16:9屏幕扩展画布，背景等比覆盖全屏，无黑边；轨道独立等比居中，HUD 根据可视尺寸定位。触屏和鼠标通过轨道逆变换定位左右命中区，侧景及HUD点击不会误触音符。三个皮肤的颜色等参数在各自场景 Inspector 中可编辑，程序化几何在脚本中集中组织。
