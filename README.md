# MusicGame / 霓虹回响

使用 Godot 4.7 打开 `project.godot`，按 F5 启动；也可打开 `music_game.tscn` 按 F6。无需 GodotParty、插件或联网服务。霓虹回响是唯一舞台实现，保留音频时钟、输入判定和音画校准。菜单可选择 Bad Apple 三档难度或双轨合成测试，并进入音画校准。午夜电台与浮光之间及主题切换入口已移除。`rhythm_prototype.tscn` 保留为独立调校入口。这是可独立运行的双键音游 demo，不包含大厅或联机。音频、谱面及字体已随仓库提供；素材来源见 `doc/credits.md` 和 `charts/bad_apple/SOURCE.md`。

- 开始 / 重来：4 拍预备拍，随后 64 拍测试；普通模式含少量八分音符，听音校准为均匀四分拍。
- 固定 A / ← 控制左轨、D / → 控制右轨。两组可混用；同轨别名重叠按压不重复计分，最后一个按键松开才释放该轨。旧改键配置不再读取。长按和键盘重复不连击。编辑数字输入框时不判定游戏输入。
- 画面提前量：正值使音符提前到线，只改变画面，不改变判定。
- 按压延迟补偿：正值从按压时刻扣除毫秒数，补偿稳定的偏晚输入。
- 下落时间只影响视觉速度；BPM 在下一次开始时生效。补偿可实时预览，比较成绩前应重开。
- 仅“应用并保存”写入 `user://party/prototypes/rhythm_1k.cfg`。恢复默认和采用建议均不自动保存。
- 切换窗口停止本轮，回来重新开始，不带着过期时钟继续。

## 调校步骤

1. 使用实际游玩设备和音频输出，打开听音校准，跟随短音敲击至少 16 次。
2. 建议值使用最近最多 32 次有效敲击的原始误差中位数，显示中位绝对偏差衡量稳定性。采用建议后重开复测。
3. 关闭听音校准，调画面提前量，使音符到线和听到短音重合。
4. 调整下落时间，完成整轮，检查 EARLY/LATE 分布。

听音校准只能估计设备延迟和个人敲击习惯的合成偏差，不是硬件测量；高抖动、蓝牙音频或不稳定节拍应多轮复测。输入校准采样窗口为 ±240 ms，普通判定为 PERFECT ±40 / GOOD ±90 / OK ±150 ms。正误差为晚，负误差为早。

## 同步实现与边界

测试音频是程序生成的原创 PCM，不下载外部资产。声音提示直接写到每个音符时间对应的采样点；没有逐帧播放节拍定时器。

时钟 = AudioStreamPlayer.get_playback_position() + AudioServer.get_time_since_last_mix() - 输出延迟估计；每轮重新读取延迟，钳制音频线程导致的小幅倒退。输入事件发生时重新采样同一时钟，不使用累计 delta。声音输出和显示器的实际延迟仍需实机校准；按键事件精度受操作系统与帧调度限制。

支持版本 2 JSON 双键 tap 谱面及配套 OGG：`key_count=2`，`notes_ms` 为绝对毫秒，`lanes` 与其等长，0 为左、1 为右。按时间和轨道升序排列，允许同刻左右同时音符，拒绝同轨同刻重复。当前无长键、打击音、在线同步或自动播放。打击音未加入，以免额外音频排队影响首次校准。设备切换后停止并重开。

参考：https://docs.godotengine.org/en/stable/tutorials/audio/sync_with_audio.html

## 验证

编辑器打开 `res://tests/rhythm_1k_test.tscn` 并 F6，输出 `RHYTHM_1K: PASS`。覆盖判定边界、偏移符号、音频采样起点、重复命中/空击、自动重复、帧停顿漏击、重开清理、焦点丢失、校准建议。

这些是逻辑与生命周期检查，不能证明实际扬声器、显示器、键盘端到端同步。人工验收需正常完成一轮、听音校准一轮，并分别确认画面提前量和按压补偿的调节方向。

## Bad Apple!! 谱面测试

默认选择 Gpop 的 Bad Apple!! Easy 转换谱。点击开始播放整首，或点击“从首音前 3 秒测试”跳过约 14 秒无音符前奏。跳过前奏只改变起播位置，谱面仍使用绝对音频时间。歌曲 BPM 不受合成 BPM 控件影响，播放至音源结尾后完成。

下拉选择支持 Easy（287 音符）、Normal（532 音符）、Hard（704 音符）及合成节拍。Normal 对应原谱 Medium；三种难度共用配套音源。切换会停止当前播放并清空本轮音符和成绩，保留按压补偿、画面提前量等调校参数；点击开始进入所选难度。Bad Apple 三档按原左/下列映射左轨、上/右列映射右轨；跨轨同刻音符保留双押，同轨重合合并，节奏时点与音源保持原样；双轨合成测试左右交替，听音校准仍在左轨使用均匀节拍。谱面与音源的作者、原文件和转换规则见 charts/bad_apple/SOURCE.md。

转换回归：`python tests/rhythm_chart_conversion_test.py`，逐一复现三种难度的全部时间戳。编辑器 F6 的 rhythm_1k_test.tscn 还覆盖真实 OGG/JSON 加载、非法时间与路径拒绝、歌曲起播及结束清理、播放中切换难度和校准参数保留。

`tests/rhythm_2k_ui_test.tscn` 覆盖左右轨隔离、双押、霓虹舞台状态与校准偏移、画面更新不重启音频、结果页和失焦停止。停止菜单仅支持重开，不加入暂停续播时钟。计分展示按 PERFECT/GOOD/OK 权重 1/0.65/0.3 计算，不改变判定窗口。
